Broschüre zum Universalofen W31, Max Ketterer, Leipzig, 2029

Die Broschüre bringt mich auf den Gedanken, dass es verschiedene "Locations"
geben muss. Z.B. in diesem Fall Leipzig als Location des Urhebers. Aber
für uns im Stadtarchiv viel interessanter wäre ja die Location, an dem
dieser Ofen bis heute tatsächlich immer noch steht.

Anders gesagt: Ein Object kann nicht nur einen Ort, sondern ein oder mehrere
Dinge referenzieren: Personen, Gebäude, Betriebe, Ereignisse, Gegenstände.

Eine aus dem Archiv generierte Karte sollte am Ende den Ofen, das Haus und die
Konditorei zeigen, nicht die Broschüre oder das Foto.

```
subjects:
  - kind: building          # person | place | building | business | event | thing
    name: Konditorei Müller
    note: am Markt
    geocode: { lat: ..., lon: ..., precision: ... }   # optional
  - kind: person
    name: Volker Hartmann
  - kind: thing
    name: Universalofen W31
    geocode: ...
```
